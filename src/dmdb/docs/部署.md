# Linux 环境下 DM8 ODBC 配置

## 1. 前置检查

### 1.1 检查 `unixODBC` 是否存在

```bash
odbcinst -j
```

如果命令不存在，需要先安装 `unixODBC`。

```bash
sudo apt install unixodbc 或 apt install unixodbc-dev
```

### 1.2 查看系统中已注册的 ODBC 驱动

```bash
odbcinst -q -d
```

如果输出中没有：

```text
[DM8 ODBC DRIVER]
```

说明达梦驱动尚未注册到 `unixODBC`。

### 1.3 查找达梦 ODBC 动态库

```bash
find / -name "libdodbc.so" 2>/dev/null
```

路径示例：

```text
/home/dmdba/dmdbms/bin/libdodbc.so
/home/dmdba/dmdbms/drivers/odbc/libdodbc.so
```

优先建议使用：

```text
/home/dmdba/dmdbms/bin/libdodbc.so
```

原因是该目录通常同时包含达梦运行期依赖库，更不容易出现二次加载失败。

没有则从官网下载安装包获取[libdodbc.so](https://eco.dameng.com/download/)

## 2. 正确配置步骤

### 2.1 编辑 `/etc/odbcinst.ini`

如果系统中已经存在 `/etc/odbcinst.ini`，直接追加下面内容即可：

```ini
[DM8 ODBC DRIVER]
Description = DM8 ODBC DRIVER for DM8
Driver = /home/dmdba/dmdbms/bin/libdodbc.so
FileUsage = 1
```

如果文件不存在，可以直接创建该文件并写入上述内容。

### 2.2 配置完成后验证驱动是否注册成功

执行：

```bash
odbcinst -q -d
odbcinst -q -d -n "DM8 ODBC DRIVER"
```

预期结果：

```text
[DM8 ODBC DRIVER]
```

以及类似：

```ini
[DM8 ODBC DRIVER]
Description=DM8 ODBC DRIVER for DM8
Driver=/home/dmdba/dmdbms/bin/libdodbc.so
FileUsage=1
```

## 3. 数据库连接

在wparse运行的机器运行以下命令，替换为实际的数据库地址、端口、用户名和密码：

```bash
isql -v -k "Driver={DM8 ODBC DRIVER};Server=localhost;Port=5236;UID=SYSDBA;PWD=password"
```
